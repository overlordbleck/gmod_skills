# Garry's Mod Lua Addons

Read [gmod_skill.md](gmod_skill.md) and follow the subskills relevant to the task. The index and linked subskills are the source of truth for addon conventions; do not load unrelated subskills.

When writing or updating a README, always read and follow the [README subskill](subskills/readme.md). Do not include addon structure, directory trees, file/folder inventories, or architecture walkthroughs anywhere in the README unless the user explicitly requests them. Structure guidance is for implementing the addon, not README content.

For every addon change, read the [manual testing subskill](subskills/testing.md). Do not create automated GMod Lua tests or mock game environments. Report which manual in-game checks were completed and which remain outstanding.
